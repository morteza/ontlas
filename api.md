# List of Desired APIs

- `search(query)`: Searches Concepts, Theories, Assertions, Tasks, Task Batteries, and Disorders for a given keyword.
- `get_concept(id, name, contrastId)`: Returns one or more concept.
- `get_task(id, name)`: Returns one or more tasks.
- `get_disorder(id, name)`: Returns one or more disorders.
- `filter_concepts(conceptId, contrastId)`.
- `get_collection(id, name)`.
- `more_info(id)`.
- `get_theory(id, name)`.
- `find_battery(id,name)`.

Note: Some APIs are extracted from Cognitive Atlas API Python Wrapper.
