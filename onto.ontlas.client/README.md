# Ontlas Client

Ontology-driven Atlas Client v1.0.1

## Requirements

Install latest nodejs, and run `npm install -g gulp bower`. Then install dependencies  using `npm install` command.

## Build & development

Run `gulp build` for building and `gulp` for a preview.

## Testing

Running `gulp test` will run the unit tests with karma.

## Generators

To generate a new component, run the following npm task:

`npm run component -- --name componentName`

or

`npm run component -- --name componentName --parent parentComponentName`
